Connect an X16

1. Connect the TexElec card to Wi-Fi.
2. Open Comms and set HOST to the official IP above.
3. Set USER once, then press SYNC.
4. Use +FR to add RODDY, or send to that user from this console first.
5. Select RODDY and send a message.

The host and username stay saved on the SD card. The browser updates automatically. On the current X16 alpha, select the conversation again to fetch its newest replies.

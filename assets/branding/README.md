# Branding assets

## `roddy-logo-transparent.png`

Transparent-background source artwork prepared from the supplied RODDY badge.
It is retained here for future asset conversion, packaging, documentation, and
About-screen work.

The current splash draws a compact badge natively with VERA primitives. This
keeps the first executable self-contained and avoids loading a large PNG, which
the Commander X16 cannot use directly.

Before release, this source image should be converted into a deliberately sized,
palette-controlled X16 asset rather than decoded at runtime.
